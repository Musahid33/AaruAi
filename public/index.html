Security notes

  • API keys never leave your machine — they are sent only to the provider you selected.
  • Run this on a computer you trust. If you host it publicly, put an auth proxy in front.
  • Use per-provider keys with the minimum permissions you need.
  • Rotate a key immediately if you think it leaked.

Backup & Sync

Backups include chats, usage and settings (including API keys — keep the file safe).

How to get API keys

Open one of these, create a key, paste it in Settings → API Manager, then enable that provider. You only need ONE to start.

    Free options

    • Ollama — run models on your own PC, completely free and private. ollama pull llama3.2 then enable "Ollama (local)" and set model llama3.2.
    • Groq — free tier, very fast (Llama, GPT-OSS).
    • Gemini — free tier API key.
    • Custom / Arena — any OpenAI-compatible endpoint: an Arena bridge, LM Studio, vLLM, Together, Fireworks, Azure OpenAI… enter its base URL + key + model.
